# street-fight

A small modular browser fighting game.

## Run locally

Open `index.html` in a browser or serve the folder with a static server.

## Project structure

- `index.html` — main entrypoint
- `styles.css` — page and game UI styles
- `data.js` — shared game definitions and constants
- `fighter.js` — fighter entity and combat logic
- `ui.js` — DOM menus, selection UI, and status updates
- `game.js` — canvas setup, game loop, and state orchestration
